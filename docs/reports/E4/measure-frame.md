## 화면 한 장 그리는 시간: 땅 굽기 전 · 후 (클라우드 가상 화면)

같은 장면: 시드 20261016, 따뜻한 지방 하나(이웃 없이), 사람 12명 뿌림 → 20명 안팎, 1배속 6초 + 멈춤 6초.
가상 화면은 그래픽 카드 없이 CPU 로 그린다(llvmpipe) — 절대값은 실제 PC 보다 훨씬 느리고, **고친 전후의 비율**만 의미가 있다.

| | 1배속: 한 장 평균 | 1배속 fps | 멈춤 fps |
|---|---|---|---|
| 굽기 끔 (`--livebake=0`, E3b 와 같은 그리기) | 133.4ms | 7.5 | 7.7 |
| 굽기 켬 (E4 기본) | 93.1ms | 10.7 | 10.0 (멈춤 · 손대지 않음 1.5초 뒤 초당 10장으로 줄임) |

- 땅 셰이더(둘레 9타일 섞기 · 무늬 · 높이 16곳)를 지방에 들어갈 때 한 번 텍스처로 굽고(타일당 8px, 가까이 보면 25×25 타일 조각을 타일당 32px 로 더 구움), 매 화면은 그 위에 물결 · 낮밤 밝기 · 불빛만 덧칠.
- 바위를 캐는 등 땅이 바뀌면 그 지방을 다시 굽는다(조각도 그 부분만 버리고 다시).
- 멈춤 + 1.5초 동안 손대지 않음 → 초당 10장, 창이 뒤에 있으면 초당 5장.
- 실제 그래픽 카드에서는 땅 셰이더가 화면 점마다 그림을 60번쯤 읽던 것이 2~3번으로 줄어든다 — 사용자 PC 의 GPU % 는 "해 볼 것"으로 확인을 부탁한다.

```
FRAMEMEASURE bake=False run_frames=45 run_ms=133.37 run_fps=7.5 paused_frames=46 paused_fps=7.7 bakes=0 people=20
FRAMEMEASURE bake=True run_frames=65 run_ms=93.13 run_fps=10.7 paused_frames=60 paused_fps=10.0 bakes=7 people=20
```
