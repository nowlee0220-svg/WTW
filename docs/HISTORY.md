## 1. 처음 아이디어 (사용자)

"월드박스(선사시대 → 미래) + 림월드"를 섞은 문명 시뮬레이터.
- 재료는 자연 생성·클릭 배치·운석으로 놓인다.
- 사람들이 재료를 실험해서 조합법을 **스스로 발견**하고, 성공·실패를 **기록**으로 남긴다. 기록이 사라지면 기술도 사라질 수 있다.
- 사람들이 무리 → 마을 → 나라를 이루고, 정치 체제·교역·법·전쟁·반란이 생긴다.
- 현실적이지만 시뮬레이터답게.

처음 아이디어의 세부 (사용자가 번호로 정리한 것):
1. 재료는 **속성**(탄다·녹는다 + 그 세기)을 가진다 — 화학 시뮬이 아니라 속성 조합으로 판정.
2. **부분 성공도 기록**("붉게 달아올랐지만 녹지 않았다") — 다음 실험의 단서.
3. 개인보다 **공동체**가 중심(v1). → v2 에서 "사람 단위"로 바뀜.
4. 일을 너무 시키면(과로) **반란**.
5. **주석 없이도** 갈 수 있는 기술 경로(구리 → 철).
6. 인구 상한과 재난으로 폭주를 막는다.
7. **체제가 규칙을 바꾼다**(노동·분배·기록).
8. 기록 매체마다 쉬움이 다르다(벽화·점토판 …), 기록이 사라지면 기술도 사라질 수 있다(기록 소실 규칙).
9. 연대기 + 나라·인물 보기 — 화면 구성은 개발자에게 맡김.
- "시대 전환을 의도적으로 만들지 않는다" — 시대 이름은 결과로 붙는 이름표.
- 플레이어 권능의 범위, 최적화, 문제점도 처음부터 함께 논의.
- 공장 같은 생산도 괜찮다(사람이 반도체 제조법을 다 알지 못하는 현실 — 분업·숙련).

일하는 방식(사용자 요청):
- 사용자는 개발자가 아니라 "소비자". 무엇을 원하는지 정확히 모를 수 있으니 **개발자 입장에서 문제를 찾아 먼저 보고하고 고쳐 달라**.
- 이 세션은 **기획·검토자**: 단계별 프롬프트를 쓰고, 다른 세션이 구현하면 "검토해줘"로 검토 → 기준 브랜치에 합치고 다음 프롬프트를 준다.
- 질문에는 "왜냐"고 물으면 **대답만**(고치지 말 것). 고치라고 할 때만 고친다.
- 프롬프트는 붙여 넣는 게 아니라 **한 줄 실행 문장**으로 ("docs/… 의 [머리말]·[단계]를 읽고 그대로 실행해줘").

## 2. v1 — 웹 버전, 공동체 단위 시뮬레이션 (끝남, 보관)

**기술**: 웹 · JavaScript · Vite · Vitest · Canvas 2D · Web Worker. 사람 800~1,500명, 무리·마을·나라 단위로 계산.
**보관 위치**: 커밋 `d0da9e9` (G2 까지).

### 단계와 결과
| 단계 | 한 일 |
|---|---|
| 0~2b | 뼈대(결정론 RNG·틱 스케줄러·ECS) · 땅과 생존(지형·기후·계절·식량) · 발견(열 반응·실험·기록) · 도구(형태 × 소재) |
| 2c | 음식·농업·추위 (핵심 완성선 시작) |
| 3a · 3a-T | 마을과 사회 · 지식과 숙련(구전 + 기록 + 손에 익음) · 단서 ⑧ 불 가두기 |
| 3a-T2 | 측정 정비(측정 도구 하나, 빠른/느린 테스트 분리) — 테스트 3시간 → 수 분 |

### v1 진행 중의 중요한 결정·사건
- **처음의 엔진 이야기**: 초반에 "어떤 엔진으로 만드는 거야?", "나중에 도트 그래픽·애니메이션을 입히고 다른 데로 옮겨도 되나?", "UI 도 예뻐야 한다"를 물음 → "웹(자바스크립트·Canvas)으로 빨리 시작하고, 시뮬과 화면을 나눠 두면 나중에 옮길 수 있다"고 답함. 이것이 뒤에 **Godot 전환**(5절)으로 이어졌다.
- **R1~R3 가 생긴 경위**: 5a 검토 뒤 사용자가 "현재 그 문제들이 왜 일어난다고 생각해?", "더 현실적으로 만들려면 무엇이 필요할까" → 검토 세션이 세 가지 구조(판단이 "지금"만 본다 · 발견에 "필요"가 없다 · 성공에 비용이 없다)를 제안 → "전부 좋네. 추가해줘" 로 R1 인구·R2 기술·R3 사회를 핵심 완성선 뒤에 넣음. 같은 때 "무엇이 왜 바뀌는지 하나도 안 보인다"는 지적으로 **V(보이는 역사)** 를 끼움.
- **계절 문제**: 2a 에서 1년이 짧아 눈이 생겼다 말았다 거슬림 → **계절 대신 지역별 고정 기후**(위도에 따라 늘 추운 곳·늘 따뜻한 곳, 보이지 않는 계절만). 사용자 제안.
- **핵심 완성선**: 2c → 3a → (3a-T) → 4a → 5a 까지는 확장(언어·종교·외교 세부 …) 없이 핵심만 만든다. 확장 아이디어는 지우지 않고 🔷 로 남김.
- **사용자가 직접 정한 것**: 질병 최소판을 5b 에서 R1 으로 앞당김 · 기술 손실을 "세계에서 사라짐"뿐 아니라 **나라 단위 끊김**으로도 센다.
- **핵심 경험 확정**: 첫날 초안 세 장면(토기·구리 → 교역 → 전쟁 → 기록이 불탐 / 작은 개입이 역사를 바꿈 / 백과의 첫 발견) → 한 줄 기준 **"인과로 흘러가는 세계"**를 맨 위에, ③ 을 **"지식의 행방"**(어디에 남았나·잃음과 되찾음·처음 나온 까닭)으로 자세히.
- **화면 손질(검토 세션이 직접)**: 기근 알림 폭주 정리 · 메뉴를 화면에 다 띄우지 않고 **림월드식 아래 메뉴 막대** · 알림을 누르면 그 자리로.
- **"방화 → 기술 끊김" 이야기**: 핵심 경험 ① "한쪽의 기록이 불타는 장면"의 대가를 R4(보관소가 생기게 — 기록할 필요)·R5(수도 서고·그 사람들에게서 끊김)로 열려 했지만, 불탄 기록이 어디서도 유일하지 않았다(사람들이 기록을 곧 다시 읽어 되살림) → 3b 로 넘김 → **v2 P2 "지식은 사람 머릿속"으로 자연스럽게 풀림**(마지막으로 아는 사람이 죽으면 끊김).
- **청동 0 문제**: 구리괴와 주석괴가 한 마을에 있어도 섞어 녹이지 않았다(단서가 없음) → R4 의 **⑨ 섞어 녹이기**로 해결(400년 7/20 시드).
- **"건강한 세계 목표" 표**(T1·T2): 인구·사망 원인(굶주림 15~30% …)·나이·기술 도달·파업·체제 존속·전쟁 기간·점령·교역 쌍·방화로 끊김·속도를 범위로 정하고 그 안에 들게 숫자를 맞춤. 숫자 튜닝은 단계마다 하지 않고 몰아서.
- **테스트 파일**: 단계마다 `npm run play` 로 만든 한 장짜리 `play.html` 을 보내 직접 해 봄(다른 세션이 만든 도구).
- **측정 속도**: 3a-T 때 측정이 3시간 → 측정 도구 하나·빠른/느린 테스트 분리·기준 파일 비교로 수 분.

### v1 에서 배운 것
- **"작은 개입이 역사를 바꾼다"·원인 사슬**은 잘 됐다. 연대기 원인 사슬, 백과 첫 발견, 끊김과 되찾음.
- 숫자만 맞추다 반대쪽으로 넘어가는 일이 잦았다(R3 에서 비용을 넣자 기술·점령이 사라짐 → T1·T2 로 되돌림).
- 측정이 느리면 모든 게 느려진다 → 측정 규칙(기준 파일 비교, 긴 측정은 단계 끝 한 번).
- **테스트플레이에서 드러난 결정적 문제**: 화면엔 사람이 보이는데 시뮬은 덩어리(무리)를 계산 → 누가 무엇을 하는지, 왜 갈라지는지(분열 이유 없음, 합쳐지는 길 없음), 왜 그 체제가 됐는지(성향 점수로 6체제 중 아무거나) 읽히지 않았다. 마을·나라가 좁은 곳에 너무 많아 주의가 흩어졌다.

## 3. v2 — 같은 웹 버전에서 사람 단위로 전환 (P0~P4, 끝남)

사용자 결정: **림월드처럼 사람 단위**, 세계 **최대 200명**, 나라는 이름만 나라·사실상 마을, 정치 요소는 유지, 특성·식인 같은 드라마.

| 단계 | 한 일 · 결과 |
|---|---|
| P0 | v1 코드 조사(살린다/고친다/버린다) · 시간 규모 결정(**1틱 = 1시간 · 하루 24 · 1년 40일**, 1배속 하루 12초, 조용하면 자동 빨리) · 사람 표 · 인물 창 |
| P1 | 욕구·특성·생각과 기분·정신 붕괴·관계·짝 출산 · **한 명씩 뿌리기 · 혼자 사는 사람 → 만남 → 짝 → 정착지** · 절차적 몸 · 일 단위 판단 |
| P1b | **배고픈 세계(림월드처럼)**: 하루 세 끼·영양실조·창고가 비었다 → 떠남·붕괴. 인구가 식량으로 멈춤(100년 113명), 굶주림 사망 ~10% |
| P2 | **지식은 사람 머릿속**: 가르치기·따라 하기·글·마지막 장인 → 죽으면 끊김 → 이웃을 보고 되찾음. 백과 "어디에 남았나" |
| P3 | **정치는 조건 + 사건**: 원로 의논·흉년에 창고를 쥔 사람이 왕·민회 · 쿠데타·반역·추방·망명 · 힘 순위 · "왜 이 체제인가" (두 세션이 동시에 돌아 하나를 고름) |
| P4 | 정착지 사이: 칸 단위 길 찾기 · 친밀도(호감 + 원한·은혜) · 교역 상단 · 습격(다침·죽음·포로·이긴 싸움 → 전쟁 영웅 왕의 길) · 혼인 · 밀입국 · 질병 전파 · 상인 체제. 브랜치 `claude/trusting-cray-4bj8wo` — 엔진 전환 결정 뒤에 끝나서 **검토·병합하지 않음**(v3 E7 에서 규칙만 참고) |

v2 측정에서 나온 기준 수치 (v3 목표의 출발점):
- 발견 목표(사람 100~150명, 해 40일): **모닥불 ~20년 · 밭 ~60년 · 토기 ~80년 · 구리 ~150년**
- 굶주림 사망 10~20% · 100년 뒤 인구 60~180(식량으로 멈춤) · 멸종 3/20 이하 · 기분 중앙값 40~55
- 정착지에서 한 사람만 아는 조합식 ~17%, 끊긴 것의 ~58% 를 되찾음(중앙값 3년)
- 체제: 원로 의논 25년 · 왕정 12.6년 · 민회 38년 / 쿠데타·반역·추방·망명이 시드마다 몇 번씩
- 속도: 100명 ~3,200 틱/초, 200명 ~1,500 (목표 3,000)

v2 에서 남은 문제: 속도(200명에서 목표의 절반), 발견이 늦음, 정신 붕괴가 많음, 창 겹침·v1 흔적, 건물이 "지었다"는 문장만 있고 지도에 없음, 맵이 사람에 비해 너무 큼.

## 4. 테스트플레이 피드백과 결정 (사용자 → 반영)

| 피드백 | 결정 |
|---|---|
| 경계·연대기가 안 보인다(초반) | 초반엔 무리뿐이라 영토가 없다 → 초반 이정표·자동 빨리 감기 |
| 국가 창 스크롤이 튄다 | 1초마다 통째로 다시 그림 → 스크롤 유지 |
| 마을·나라가 좁은 곳에 너무 많다, 빨간 선·네모가 뭔지 모른다, 건물·사람이 뭘 하는지 모른다 | **원칙: 정보 전달의 직관성이 최우선** — 지도 모드·확대 단계·모든 것에 "왜"(크루세이더 킹즈 참고) |
| 시뮬레이터보다 **게임**에 가깝게 | 월드박스(신의 시점) 기본 + 크킹의 정보 전달 + 가까이 보면 림월드 |
| 빈 만년설 | 그대로 둠 — 추위를 이기는 옷이 생기면 **쫓겨난 사람들이 북쪽으로** |
| 시작은 내가 뿌린 사람만 | 빈 세계에 한 명씩(또는 가족) 뿌린다 |
| 무리는 분열만 하고 이유도 없다 | 개인의 선택(떠남·망명·밀입국·추방·반역), 합류, 친족·부족 |
| 왕정이 되는 이유가 설득력 없다 | 체제는 조건 + 사건 |
| 동료·마을·공동체·국가 단위, 나라가 아니어도 다툼·마을 전쟁 | **여러 겹 단위 + 다툼의 사다리**(말다툼 → 주먹싸움 → 피의 복수 → 습격 → 마을 전쟁 → 정복, 화해·배상·혼인으로 풀림) |
| 건물이 저장소뿐, 눌러 볼 수 없음, 크기가 같아 재력·예술이 없음 | 사람이 실제로 짓기 · **타일 단위 크기** · 품질 · 재력 · 예술 · 건물 창 |
| 이야기 생성기를 만들고 싶다 | **이야기가 결과물**: 인물 전기·이야기 줄기·책 같은 연대기·스토리텔러 |
| 능력치가 없거나 안 보인다 | **제안(확정 전)**: 타고난 능력 5(힘·손재주·영리함·말재주·담력) + 기술 + 열정 🔥 + 마우스 카드 |
| 창끼리 가린다 | 선택 정보 칸 하나(탭) + 큰 창은 하나씩 |
| 정착하면 땅과 리더를 정해야 | 정착 사건 = 땅 + 우두머리 |
| 창고를 지었다는데 안 보인다 | "알아냈다"와 "지었다"를 구분 |
| 타일 하나에 자원 하나 | **타일 하나에 오브젝트 하나, 다루는 법에 따라 여러 자원**(사과나무 → 따면 사과, 베면 나무) |

| 작업대 | 작업대마다 조합식, 연구로 업그레이드, **한 사람 한 작업대**, 나중에 **자동화** → 200명으로도 산업까지 |

### 성능 전략 (사용자: "틱이 늘어나는 건 림월드에도 있던 문제, 컴퓨터 성능을 더 끌어내는 방식도 좋다")
1. **일 단위 판단** — "8시간 잠", "3시간 사냥"처럼 한 번 정하면 끝날 때까지 다시 판단하지 않는다(급한 배고픔·추위·위험만 끊는다).
2. **조용한 사람은 건너뛰기** — 자는 사람·같은 일을 이어 하는 사람은 거의 계산하지 않는다.
3. **컴퓨터를 더 쓰기는 최후 수단** — 지방마다 CPU 하나(지방끼리는 하루 경계에서만 주고받아 결정론 유지), 무거운 계산은 더 빠른 언어로.
목표: 200명 헤드리스 ≥ 3,000 틱/초. v2 에서는 세 단계 연속 절반쯤에 머물렀다 — v3 는 처음부터 이 구조로.

### 두 겹 지도의 세부 (정한 것)
- 행성(큰 타일) = 대륙·기후·영토·이동이 보이는 곳 / 지방(작은 타일, 150×150) = 사람·건물·오브젝트.
- **한 지방에 정착지 하나** — 지방이 영토 단위, 지방 경계가 국경. 붙은 지방에서 사냥감을 쫓다·길을 잃어·몰래 넘어오는 일은 있다.
- 빈 지방은 **멈춤**(사람이 다시 오면 흐른 시간만큼 한 번에 맞춤). 사람이 머무는 지방은 **모두** 자세히 계산(보는 곳만 계산하면 보는 곳에 따라 역사가 달라짐).
- 화면: 내부적으로는 이어 붙어 있지만 **보는 집단의 땅만 밝게, 나머지는 검게**(림월드). 국경 너머는 이름만, 넘어온 사람은 다른 테두리. "이웃도 보기"는 선택.
- **국경 세 종류**: 느슨함(신경 안 씀) · 지킴(들키면 쫓겨나거나 원한) · 닫힘(붙잡히거나 싸움, 몰래 들어오면 밀입국) — 지도자·관계·법으로 바뀜.
- **행성 지도의 표시**: 정착지 🏘 · 유목 무리 ⛺(움직이는 정착지, 계절따라 이동) · 상단 🐂 · 습격대 ⚔ · 여행자·망명자 🚶 — 모두 출신 집단 색, 목적지까지 선. 누르면 일행 창.
- 집단을 누르면 그 집단이 차지한 지방들이 화면에 들어오고, 정착지를 다시 누르면 그 지방으로 들어감. 지방 사이 이동은 여정(행성 위를 며칠~몇 주, 가져간 식량), 소식·병도 사람을 따라감.
- 지방마다 RNG 스트림을 따로 → 지방이 새로 생겨도 다른 지방 역사가 흔들리지 않고, 나중에 **지방마다 CPU 하나씩** 돌려도 같은 결과.

### 질문으로 정한 것
- 한 판: 몇 시간 ~ 며칠(리듬을 잘 조절) · 저장/불러오기, 꺼 둔 동안은 멈춤
- 세계 시작: 내가 뿌린 사람만 · 멸종하면 연대기를 책으로 남기고 세계는 그대로, 새 사람은 흔적 속에서 산다
- 플레이어: **적극적 개입**, 권능 = 재난·축복·지형·자원 (사람 마음을 직접 바꾸지 않음), 계시는 **영감만**, 제한 없음(샌드박스), 신앙은 세계 속 종교와 기록·업적
- 문화: 갈라진 집단은 말·관습·이름이 달라진다 · 동물은 림월드처럼 · 경제는 물물교환 → 화폐를 발견 · 기술은 산업·전기까지 먼저 · 수위는 담담한 문장 + 단순한 표시
- AI 가 쓰는 문장은 쓰지 않는다 · 주인공 따라가기·사연 있는 물건·역사의 구전·사건이 붙은 지명은 넣는다
- 새 세계 설정: 행성 크기·바다 비율·기후·시드 · 1년 40일 유지
- 직접 플레이 모드: 아직 고민 — 후보는 정착지 하나 운영(림월드식) · 한 사람 조종 · 나라 운영(크킹식), 고르지 않음
- **승리 조건은 없다** — 크루세이더 킹즈처럼 지켜보고 개입하는 역사 (G1 때 결정)

- **결정**: 사람 상한 기본 300 / 최대 500 유지(2분 목표는 측정 편의용, 게임은 괜찮음 — 측정은 300 기준, 속도는 E8) · 열정은 꺼 두고 E6 에서 재시험.
- **사용자 질문에서 바뀐 것**
  - "사람은 지방을 넘어가나? 옆에 물이 있으면? 물이 없으면 떠도나?" → 넘지 못하고, 옆 지방 물을 모르고, 물이 없으면 "찾아다닌다"면서 아무 데나 걷다 죽었다 → 지방 안에서는 똑똑하게 찾기(보임 · 기억 · 따라감 · 낮은 곳으로)로 고침 + **지방 넘기를 E3b 로 앞당김**.
  - "이름도 사회가 정하는 것 / 이름은 언어의 연장 / 언어는 모여 살려고 만든 것, 지방마다 다르고 사투리도 있다" → **언어 뼈대**를 E3 에 넣고(말씨 · 닮아 감 · 알아듣기 % · 처음엔 이름 없음 → 무리에서 이름 · 뜻 있는 아이 이름 · 걸러내기 · 받침 조사 · 말풍선), 기획서에 **14-1 언어** 절(원칙 · 타협 다섯 · 목표 숫자 · 보여 주기 · 단계별 범위 · 문제 대비)을 새로 씀.
  - 검토에서 찾아 고친 것: 이름 "바보" · 숲에서 사람이 안 보임 · 지도가 좁음.
- **검토에서 드러난 큰 문제 → E3b**: 아무 땅이나 고르면 **100곳 중 90곳에 마실 민물이 없다**(열대우림 · 온대림까지). 지방의 물이 행성의 강 · 호수에서만 오기 때문 — 비가 오는 땅이면 개울 · 샘 · 웅덩이가 있어야 한다. 뿌린 사람의 48% 가 "지방 안에 물이 없어" 목말라 죽음.
